# Codex Skills Foundation

A provider-neutral engineering foundation for Codex, Codex Cloud, Claude Code, Hermes Agent, and other Agent Skills compatible clients.

It combines portable skills, narrow read-only specialist agents, deterministic routing, evidence gates, platform adapters, and behavior evaluations. The default is a single writing agent. Delegation is used only when independent work can materially improve quality or speed.

Run:

```bash
./scripts/bootstrap.sh
```

or on Windows PowerShell:

```powershell
./scripts/bootstrap.ps1
```

See [`README.md`](README.md) for the complete Turkish guide and [`docs/architecture.md`](docs/architecture.md) for the design.
