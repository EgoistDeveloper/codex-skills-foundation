# Privacy

Codex Skills Foundation contains instructions, schemas, and local validation scripts. It does not ship telemetry, analytics, credential collection, remote logging, an MCP server, or a network client.

The plugins may instruct an agent to use tools already available in the host product. Data handling by Codex, ChatGPT, Claude Code, GitHub, or another host remains governed by that host's settings and privacy terms. Review host permissions before enabling repository, network, browser, or connector access.

Do not place secrets, personal data, proprietary source, or unredacted traces in eval artifacts or handoff files. Repository fixtures and reports should be redacted before sharing.
