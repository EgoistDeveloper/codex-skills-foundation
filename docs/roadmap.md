# Roadmap

## 0.1 — Foundation

- Portable skills-only plugin.
- Codex and Claude marketplaces.
- Read-only specialist agents.
- Deterministic routing, evidence gate, repository validation, and eval fixtures.
- Laravel, design, Cloud, research, debugging, review, and verification workflows.

## 0.2 — Live qualification

- Run the documented cases in current Codex app, Codex Cloud, Claude Code, and Hermes.
- Measure token and diff behavior.
- Refine trigger descriptions using false-positive and false-negative evidence.
- Add tested install/update/uninstall paths per client.

## 0.3 — Project profiles

- Optional Laravel profile with Laravel Boost detection.
- Optional Vue/Inertia and Blade design profiles.
- Profile schema and merge rules.
- Versioned project bootstrap generator.

## Not planned without separate approval

- Provider credential bridges.
- Automatic external-model routing.
- A hosted service.
- Default MCP servers.
- Recursive autonomous agent trees.
- Self-modifying production skills without human review.
