## Install or upgrade

Use the immutable tag for a reproducible Codex installation:

```text
codex plugin marketplace add EgoistDeveloper/codex-skills-foundation --ref v0.3.0-beta.2
codex plugin add engineering-foundation-core@egoist-engineering-foundation
```

For an existing pinned marketplace, remove installed packages and the old marketplace entry, add the new tag, and reinstall as described in [`../public-beta.md`](../public-beta.md). Verify downloaded archive hashes against the published `SHA256SUMS` asset.

`v0.3.0-beta.1` remains an immutable historical prerelease; its tag and assets were not changed.
